# Jahmeir AI Executive Command Center

An evidence-backed personal operating system for coordinating multiple independent command centers across career, education, acting, dance/content, finance, health/performance, fashion, relationships, and long-term mobility.

This project is designed as a durable local system, not a generic chatbot prompt. It uses explicit ownership, source-of-truth files, bounded delegation, review gates, recovery handoffs, and human approval for consequential actions.

## What this demonstrates

- Cross-domain prioritization through a shared executive layer
- Separate domain systems that remain independently useful
- Durable state, recovery indexes, ledgers, templates, and handoffs
- Evidence requirements that distinguish facts, recommendations, drafts, and completed actions
- Capacity-aware planning across time, money, attention, energy, and AI effort
- Privacy-aware separation between public architecture and private personal records

## Architecture

The project is organized into an executive layer, system registry, operational ledgers, reusable templates, Codex execution guidance, domain command centers, current-state recovery, and a knowledge layer. A concise public overview is available in [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md).

The active personal records are intentionally excluded from the public-facing Git history. This repository documents the system design and portfolio-safe implementation patterns without publishing résumés, applications, financial records, health data, raw media, or private opportunity research.

Before publishing, run `bash scripts/verify-public-tree.sh`. The same check runs automatically on GitHub for pull requests and updates to `main`.

## Status

The system is an evolving personal project. The repository boundary and public documentation are established first; additional sanitized examples can be added as they are verified.
